# Веб-застосунок "The Met Museum Collection"

Цілісний багатосторінковий React-застосунок для перегляду та пошуку колекції Нью-Йоркського музею мистецтва Метрополітен (The Metropolitan Museum of Art).

## Опис джерела даних (Met Museum API)

У проєкті використовується публічне API: `https://collectionapi.metmuseum.org/public/collection/v1/`

### Основні ендпоінти:
* `GET /search` — серверний пошук ідентифікаторів об'єктів за запитом та категоріями[cite: 7].
* `GET /objects/{objectID}` — отримання детальної інформації про конкретний експонат (назва, автор, рік, матеріал, розміри, зображення, відділ)[cite: 10, 15].
* `GET /departments` — отримання довідника відділів музею[cite: 15].

### Розподіл виконання фільтрації, сортування та пагінації:

1. **Серверний пошук (`q`):**
   * **Де виконується:** На сервері[cite: 7].
   * **Обґрунтування:** База музею містить понад 400 000 об'єктів, тому пошук за текстом надсилається безпосередньо в параметр `q`[cite: 7].

2. **Фільтр за відділом (`departmentId`):**
   * **Де виконується:** На сервері[cite: 7].
   * **Обґрунтування:** Передається в параметр `departmentId` ендпоінта `/search` для відсіювання категорій[cite: 7, 15].

3. **Фільтри `hasImages` та `isHighlight`:**
   * **Де виконується:** На сервері[cite: 7].
   * **Обґрунтування:** Сервер повертає тільки ті об'єкти, які мають фотографії та є шедеврами колекції[cite: 7, 15].

4. **Фільтр за матеріалом (`medium`: Oil, Print, Earthenware):**
   * **Де виконується:** На клієнті[cite: 7].
   * **Обґрунтування:** API Met Museum не надає окремого параметру для точної фільтрації за технікою/матеріалом у пошуку, тому фільтрація відбувається в React[cite: 7].

5. **Сортування та пагінація:**
   * **Де виконується:** На клієнті[cite: 7].
   * **Обґрунтування:** API повертає лише масив ідентифікаторів `objectIDs`. Розбивка на сторінки та сортування виконуються на стороні клієнта[cite: 7, 15].
